# Лабораторная работа № 3

## Цель работы

Изучить основы языка JavaScript: типы данных и их преобразования, операторы, циклы, рекурсию, функции и функциональные выражения, стрелочные функции, замыкания, объекты и их глубокое сравнение.

## Задание

Написать набор функций на языке JavaScript, реализующих требуемый функционал из каркаса проекта [js-tasks](https://github.com/teach-kirshdv/js-tasks), и загрузить проект в репозиторий.

## Реализованные функции (src/core.js)

| Функция | Задание | Используемый приём |
|---|---|---|
| `isInteger(n)` | Проверка, является ли число целым | Побитовый оператор ИЛИ: `(n \| 0) === n` |
| `even()` | Массив чётных чисел от 2 до 20 | Цикл `for` с шагом 2 |
| `sumTo(n)` | Сумма чисел от 1 до n | Итеративное накопление (цикл) |
| `recSumTo(n)` | Сумма чисел от 1 до n | Рекурсия с базовым случаем `n <= 0` |
| `factorial(n)` | Факториал числа | Цикл `for`, накопление произведения |
| `isBinary(n)` | Проверка, является ли число степенью двойки | Битовая операция `n & (n - 1) === 0` при `n > 0` |
| `fibonacci(n)` | N-е число Фибоначчи | Итерация с двумя переменными (prev/curr) |
| `getOperationFn(initialValue, operatorFn)` | Функция, возвращающая функцию-аккумулятор с операцией | Функция высшего порядка, замыкание |
| `sequence(start, step)` | Генератор арифметической последовательности | Завод (factory function), замыкание, параметры по умолчанию |
| `deepEqual(a, b)` | Глубокое сравнение двух значений/объектов | Рекурсивное сравнение свойств, `Object.is` |

## Как запустить тесты

Требуется установленный Node.js.

```bash
npm install   # установка зависимостей (mocha, prettier)
npm test      # запуск модульных тестов Mocha
```

Ожидаемый результат: `16 passing`.

## Файлы проекта

- `src/core.spec.js` — модульные тесты из каркаса (не изменялись);

# Core Javascript

## Как пользоваться

Для того, чтобы всё корректно работало, у вас должен быть установлен [node](https://nodejs.org/en/) и [git](https://git-scm.com/)

-   Скачайте проект к себе. Есть 3 способа:
    -   Скачайте проект как архив.
    -   Склонируйте текущий репозиторий.
    -   Сделайте fork репозитория и склонируйте его к себе.
-   Скопируйте содержимое проекта в свой репозиторий по курсу.
-   Разберитесь в структуре проекта.
-   Задания находятся в `src/core.js`.
-   Перед тем, как начать делать задание, выполните `npm install`.

\*Для особо любопытных: разобраться с менеджером пакетов [yarn](https://yarnpkg.com/getting-started).
