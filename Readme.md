# Лабораторная работа № 2

## Задание на лабораторную работу

**Цель лабораторной работы:** изучение основ HTML и CSS.


**Задание на программирование:** разработать многостраничный web-сайт на произвольно выбранную тему с использованием технологий HTML и CSS, загрузить проект в репозиторий.


**Требования к web-сайту:**

1.	Количество страниц – от 3 до 5.

2.	Требования к HTML:

    1)	Использование блочных и строчных элементов.
    2)	Ссылки – от 1 шт.
    3)	Картинки – от 1 шт.
    4)	Таблица – от 1 шт.

3.	Требование к CSS:

    1)	Отдельный подключаемый файл.
    2)	Обязательное использование как минимум 3 видов селекторов.
    3)	Использование цвета.
    4)	Использование различных видов выравнивания в таблице (по левому/правому краю и по центру).

4.	Запрещено использовать JS, Bootstrap и любые другие библиотеки и фреймворки, всё реализовать самостоятельно.

**Тема сайта:** кофейня «Аромат»

**Web-программирование. Современный CSS и ООП на JavaScript.**

Сайт кофейни из лабораторной работы №2, модернизированный по требованиям ЛР №4
и загруженный в ветку `lab4`.

## Что реализовано

| Требование | Где реализовано |
|---|---|
| Вёрстка с помощью Flexbox — 1 страница | `index.html`: шапка (`header__inner`), ряд карточек (`features__row`), блок «о нас» (`about`) |
| Вёрстка с помощью Grid — 1 страница | `menu.html`: сетка `menu__layout` из двух колонок (`grid-template-columns: repeat(2, 1fr)`), модификатор `--wide` занимает обе колонки |
| Все цвета — только через CSS-переменные | `css/style.css`, блок `:root`; в правилах используются только `var(--…)` — включая тени и градиенты |
| Анимация с помощью CSS | Главная страница: пар над чашкой кофе — `@keyframes steam-rise` (три облачка, `filter: blur`, `animation-delay`); дополнительно появление баннера `@keyframes fade-up` |
| Форма с ≥ 3 типами полей и кнопкой отправки | `order.html`: text, tel, email, select, number, radio, textarea, checkbox + кнопка `type="submit"` |
| Класс с конструктором и методом форматированного вывода на консоль | `js/main.js`: класс `CoffeeOrder`, конструктор и метод `printToConsole()`; объект создаётся при отправке формы, затем вызывается метод (`console.log` + `console.table`) |
| Бонус: методология БЭМ | Все классы названы по схеме `блок__элемент--модификатор` (`nav__link--active`, `menu__category--wide`, `form__input` и т. д.) |
